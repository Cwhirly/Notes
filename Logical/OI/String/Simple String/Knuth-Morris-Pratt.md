## 2、Border 以及 Next 数组
一个长度为 $l$ 的字符串有 $l-1$ 个前缀以及 $l-1$ 个后缀。
设字符串 $s$ 的前缀所构成的集合为 $\Pi$，后缀所构成的集合为 $\Sigma$，定义该字符串的 Border 为：
$$
{\displaystyle\max_{x\in\Pi\cap\Sigma}|x|}
$$
$|x|$ 为字符串 $x$ 的长度。  
通俗地，即最长公共前后缀的长度。

如果将字符串 $s$ 看做成一个数组，以下标 1  为起点，那么定义 $next_i$ 为 $s$ 的长度为 $i$ 的前缀的 Border。
>
>举个例子：
>$\texttt{ababbaababa}$ 的公共前后缀为 $\texttt{a},\texttt{aba}$，其中最长的长度为 3，所以它的 Border 为 3。
>它的 Next 数组为：0,0,1,2,0,1,1,2,3,4,3，这可以很容易推出来。
>

如何计算 Next 数组？
根据一般的思路，首先需要知道如何求出每个字符串的 Border。
很容易，$\Theta(n)$ 地枚举每一个长度的前缀与后缀，然后判断每对长度相同的前后缀是否相等。注意此处暴力判还要加一个 $\Theta(n)$，用 Hash 就可以降到 $\Theta(1)$ 了。这还仅仅是求一个字符串的 Border 的复杂度。
所以求 Next 就是 $\Theta(n^2)$ 或 $\Theta(n^3)$。
现在考虑优化这个过程。
## 3、Next 数组的线性求法
想要 $\Theta(n)$ 地求 next 数组，就不能采取直接模拟 next 数组定义的方式了。
所以现在需要抓住每个 next 数组中的值的联系，像 DP 一样把它求出来。
不妨先考虑 $next_i$ 与 $next_{i-1}$ 的联系。
![[屏幕截图 2024-11-19 193644.png]]
如果 $s_i=s_{j+1}$，那么如图，$next_i=next_{i-1}+1$。
此处有一个性质，$\forall i$，我们有 $next_i\le next_{i-1}+1$ 通过反证法很容易可以得到。

如果 $s_i\neq s_{j+1}$，那么由下图
![[Pasted image 20241121002833.png]]
我们让 $j\gets \text{next}_j$，此时四个绿框中的子串都相等。再判断 $s_i\stackrel{?}{=}s_{j+1}$，如果不相等，再让 $j\gets \text{next}_j$，直到 $j$ 为 0 或相等为止。
代码如下：
```cpp
nxt[1]=0;
int j=0;
for(int i=2;i<=n;i++){
    while(j&&s[j+1]!=s[i]) j=nxt[j];
    if(s[j+1]==s[i]) j++;
    nxt[i]=j;
}
```
尽管这是一个 `for` 嵌套一个 ` while `，但复杂度仍是 $\Theta(n)$，感性理解即可。
