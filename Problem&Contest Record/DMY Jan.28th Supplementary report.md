# 第二题  
## 题目大意   
给一个序列，可以交换 $k$ 次两个数，求交换后最大子段和。
## 解题思路
**10 pts**：  
全是正的，怎么交换答案都一样，直接加起来即可。
**30 pts**：
满足有序，所以把正的加起来即可，无需交换。  
**100 pts**：
枚举可能的最大子段 $[l,r]$（$O(n^2)$）。
找出里面最小的 $k$ 个，与外面最大的 $k$ 个互换。
# 第三题

**20 pts**：
